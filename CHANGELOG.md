# Changelog

Todas as mudanças relevantes deste projeto serão documentadas neste arquivo.

## [Não lançado]

### Planejado

- conectores adicionais para catálogos públicos;
- importação de benchmarks reproduzíveis;
- traduções comunitárias;
- perfis de hardware regionais.

## [0.1.0] - 2026-08-09

### Adicionado

- interface gráfica com 14 áreas de análise;
- CLI multiplataforma;
- inventário Windows, Linux e macOS;
- catálogo SQLite com sincronização Hugging Face e descoberta GitHub;
- motor de compatibilidade explicável e BerchaScore;
- montador completo de PC com pesquisas em lojas;
- relatórios HTML, TXT, JSON e PDF;
- executável Windows portátil;
- testes automatizados e documentação metodológica.
