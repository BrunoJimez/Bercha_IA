# Política de segurança

## Versões suportadas

| Versão | Suporte |
| --- | --- |
| 0.1.x | Sim |
| anteriores | Não |

## Relatar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue. Use a opção **Report a
vulnerability** na aba Security do repositório. Inclua versão, sistema operacional,
impacto, passos mínimos de reprodução e uma forma segura de contato.

O recebimento será confirmado assim que possível. A correção e a divulgação serão
coordenadas conforme gravidade, impacto e disponibilidade de uma mitigação.

Nunca envie tokens do Hugging Face, GitHub ou qualquer outro segredo em relatórios.
